# Junior Astronaut Mission Trainer 🚀
لعبة تعليمية ثلاثية الأبعاد: الطفل رائد فضاء بيزور 29 جرم زارتهم ناسا (كواكب، أقمار، كويكبات، مذنبات، الشمس) ويدير موارده بقرارات حقيقية.

## التشغيل
1. افتح الفولدر ده في VS Code (File > Open Folder).
2. نزّل إضافة **Live Server** (Ritwick Dey) ثم كليك يمين على `index.html` > **Open with Live Server**.
3. أو افتح `index.html` مباشرة في Chrome. مفيش مكتبات خارجية ولا نت.

## الملفات
- `index.html`: هيكل الشاشات (دخول، خريطة المستويات، اللعب، النتيجة، المصادر، سجل الاكتشافات).
- `style.css`: التصميم.
- `game.js`: كل المنطق، وفيه أقسام معنونة بـ `// ======`.

## أهم الأماكن في game.js
- `LEVEL_EVENTS` و`UNI`: المواقف والاختيارات (نسبة النجاح وتأثير كل اختيار على الموارد).
- `BODIES` و`HZ`: الأجرام الـ 29 وقوالب المشاكل اللي بتتولد منها أحداث كل جرم.
- `decay()`: معدل نزول الموارد كل يوم (من 3 لـ 11 حسب المستوى).
- `GL`: محرك WebGL (الخريطة 3D، الكواكب، الصاروخ).

## للـ Backend
التقدم والرواد محفوظين حاليًا في localStorage (`ja_profiles` و`ja_save_<id>`).
لربطه بقاعدة بيانات بدّل الدوال: `saveProgress` و`loadProgress` و`saveProfiles` و`loadProfiles`.
